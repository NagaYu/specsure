# SpecSure benchmarks

Generated by `python scripts/build_benchmarks.py` from the saved result files. Every number below is a measured run;
anything that has not been run is marked **not measured**. Synthetic and real-data results are never mixed in one table.

## 1. Gate: deterministic verifier vs baselines (synthetic, handwritten challenge sets)

- **v1** = 120 handwritten claims (60 true / 60 erroneous), committed at `24905f8ca5dd` **before** the verifier was ever run on it, then run exactly once. The v1 set itself is kept private so it stays unseen.
- **v0** = 60 handwritten claims used as the development set (the verifier was tuned on it — optimistic).
- Severity: S1 safety/legal (ingredients, allergens), S2 invalidates the purchase, S3 degrades the experience.

| System | Set | BLOCK precision | S1 errors passed | S2 recall | True-claim PASS rate | UNKNOWN rate |
|---|---|---|---|---|---|---|
| Deterministic verifier | v1 (unseen, single run) | 94.7% | 0 / 15 | 91.3% | 91.7% | 4.2% |
| Deterministic verifier | v0 (dev) | 91.3% | 0 / 9 | 92.3% | 88.2% | 8.3% |

Regression replay with the current code (pinned SpecGate baseline, 2026-11-01): v0: BLOCK precision 91.3%, S1 passed 0, UNKNOWN 8.3%; v1: BLOCK precision 94.9%, S1 passed 0, UNKNOWN 3.3%. The v1 number differs from the single-run record above by one claim (a counter word, 「本」, became parseable when pack-count support was added).

## 4. Real-data pilot (internal only — aggregates)

- 30 products hand-attributed from the official pages of 5 manufacturers; site terms were reviewed for 11 (accepted 5/11, all provisionally and for internal research only).
- **Redistributable: 0 / 30** — none of this data is published.
- Ingredient vocabulary coverage on real labels: 51.2%.
- Verifier on claims generated from these snapshots (circular, like section 2): BLOCK precision 100.0%, true-claim PASS rate 99.1%, UNKNOWN 0.6%.
- Ingestion time: 0.27 min/product measured for the **AI agent** doing the work — human ingestion time is **not measured**.

## What these numbers do not show

- Performance on real shopping-agent answers (none collected yet; collection is manual and gated on each agent's terms).
- An LLM-judge comparison: not run — the author chose not to spend on API calls; see results/gate-judge.md.
- Statistical confidence: the challenge sets are small (one claim moves v1 metrics by ~1–2 points).
